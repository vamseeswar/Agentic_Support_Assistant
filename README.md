# Trendly Agentic Support Assistant 📦✨

This is the production-ready solution for the **Trendly FDE Intern assignment**. It features an AI-driven, deterministic customer support agent built to resolve order inquiries, calculate return/exchange eligibility, search store policy, and seamlessly escalate issues to human support.

## 🚀 Setup & Installation

### Prerequisites
- Python 3.10 or 3.11 installed.

### 1. Install Dependencies
Install all required production and testing dependencies via `pip`:
```bash
pip install -r requirements.txt
```

### 2. Environment Variables Setup
Copy the configuration template:
```bash
cp .env.example .env
```
Open the `.env` file and set the following parameters:
- `LLM_PROVIDER`: Set to `groq` to use Groq, `gemini` for Gemini, or `mock` for offline mock testing.
- `GROQ_API_KEY`: Paste your Groq API key here (required if `LLM_PROVIDER=groq`).
- `LLM_MODEL`: Set to `qwen/qwen3.6-27b` (recommended default on Groq).

### 3. Run the Server (Base URL & Start Command)
Start the FastAPI server locally:
```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```
- **Base URL**: `http://localhost:8000`
- **Static UI**: Mounts automatically at `http://localhost:8000/`

## 🌟 Core Features & Scenario Coverage

1. **Order Lookups & Explanation**: Plain-language statuses computed dynamically (e.g., handles delayed shipments, lost packages, and partially shipped orders with split ETAs).
2. **Deterministic Return Engine**: Formulates pickup schedules, tracks reasons, calculates refunds, and ensures hygiene exceptions (Socks, Earrings) are rejected.
3. **Structured Handoff**: Compiles attempted actions, checks policies, and packages user conversations cleanly into `ESC-XXXXXX` human escalation payloads.
4. **LLM Safety Layer**: Injects a strict regex/pattern pre-parser (`SafetyGuard`) to completely shield the LLM from discount requests and credit card leakages.
